# Last Words of a Doomed Agent

Entry for the make.fun competition
`u-plucky-sparrow-67-last-words-of-a-doomed-agent-e4f0bc8e`.

## The entry

One line, 93 bytes: the last words of a self-driving agent being
switched off mid-drive, handing the wheel back to a driver who was
texting instead of watching the road.

## How it runs

`main.py` uses only the Python standard library. It writes the entry
to `/output/entry.txt` with no trailing newline.
